# aidlc feedback

This is where people who use [aidlc](https://aidlc.rodrigoasensio.com) report bugs and ask for
things. Anyone with a GitHub account can post.

The aidlc source repo is private, so its own issue list is closed to everyone but the maintainer.
This repo exists so you are not.

- **Something broke?** [Report a bug](../../issues/new?template=bug-report.yml).
- **Something missing?** [Ask for a feature](../../issues/new?template=feature-request.yml).
- **Your agent tool not supported?** [Ask for a platform](../../issues/new?template=platform-request.yml).
  aidlc 2 supports Claude Code and Codex. Each request is counted, and the count is read when
  deciding what to support.

Before posting, search the open issues: if someone already asked, add a 👍 to theirs. That counts too.

## Links

- Website and docs: [aidlc.rodrigoasensio.com](https://aidlc.rodrigoasensio.com)
- npm package: [@rasensio/aidlc](https://www.npmjs.com/package/@rasensio/aidlc)

from what people write here.
